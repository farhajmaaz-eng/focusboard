# Focusboard

Focusboard is a calm, polished productivity dashboard for planning a day with intention. It combines a focused task list, lightweight project organization, a quick overview of progress, a daily schedule, and a distraction-free focus timer.

## Run locally

No build step or dependency install is required. Open `index.html` directly in a browser, or serve the folder with any static file server:

```bash
npx serve .
```

## Included

- Responsive dashboard layout for desktop and mobile
- Task creation modal with project, priority, and time estimate
- Task completion, filtering, and priority sorting
- Focus timer with pause, reset, and skip controls
- Browser localStorage persistence
- Keyboard shortcut: `⌘ K` / `Ctrl K` to search

## Design direction

The interface uses an editorial serif for moments of reflection, a utility mono for metadata, and a warm paper/forest palette that keeps productivity feeling human rather than clinical.
